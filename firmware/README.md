# ESP32-S3 Firmware

This directory contains the embedded firmware for the Sign Language Capture and Illustration System.

## Responsibilities

- Read flex sensor values.
- Acquire motion data from the MPU6050 over I2C.
- Process and transmit sensor readings.
- Support gesture recognition and communication with the dashboard.

## Hardware Configuration

- Controller: ESP32-S3
- Flex sensors: thumb, index, middle, ring, and pinky
- MPU6050: SDA and SCL connections according to the project's hardware configuration
